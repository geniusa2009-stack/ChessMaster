## 🧱 معماريّة المشروع (Architecture)

تم بناء المنصّة وفق معماريّة هندسية محكمة تفصل المنطق عن العرض، وتغلّف كامل الكود داخل **نطاق خاص (IIFE)** لحماية البيانات من العبث.

### 1) نظام الحسابات والجدار الحديدي (LocalStorage Iron-Wall)
- شاشة **Sign Up / Login** بتبويبين، مع تحقّق صارم من المدخلات (صيغة البريد + طول كلمة المرور) قبل السماح بالدخول.
- تُخزَّن بيانات الطالب مرّة واحدة في `LocalStorage` مع **رمز هويّة مشفّر (Session Token)** لمنع الانتحال.
- نقاط الخبرة (XP) محميّة بـ **بصمة تحقّق (checksum) + مراقب لحظي (Watchdog)** يعيد القيمة الأصلية تلقائياً إذا حاول أحد تعديلها من الـ Console.
- كامل الدوال والبيانات مغلّفة داخل `(function(){ ... })()` فلا تتسرّب أي دالّة إلى النطاق العام (Window).

### 2) محرّك التحليل Stockfish داخل Web Worker
- يُحمّل محرّك **Stockfish** عبر CDN ويُشغَّل داخل **Web Worker** منفصل تماماً عن الخيط الرئيسي — لمنع أي تهنيج (Lag) في الواجهة أثناء الحساب العميق.
- خوارزمية **تحليل المباراة اللحظي (Game Review)** تمرّر كل نقلة على المحرّك، وتحسب فاقد السنتيباون (Centipawn Loss)، وتصنّف النقلات علمياً: 🌟 عبقرية / ✅ الأفضل / 👍 جيّدة / ⚠️ عدم دقّة / ❌ خطأ فادح — مع تلوينها فوق المربّع مباشرة.
- **عمود التقييم (Evaluation Bar)** تفاعلي يتحرّك لايف ويُظهر تفوّق الأبيض/الأسود رقمياً (مثال: `+1.5` / `-2.3`).
- مقيّم احتياطي داخلي (Negamax + Piece-Square Tables) يضمن استمرار التحليل ذا المعنى حتى بدون إنترنت.

### 3) نظام إضاءة المسار ومحاكاة الألغاز التتابعية
- بمجرّد لمس أو سحب أي قطعة، تُضاء **جميع المربّعات القانونية** فوراً بدوائر **خضراء نيون شبه شفافة** (وحلقات على مربّعات الأكل)، وتختفي عند الإفلات.
- نظام **ألغاز تتابعي مقفل**: لغز واحد على الشاشة، ولا يُفتح التالي إلا بحلّ الحالي، بحدّ أقصى **10 ألغاز قاسية يومياً** محفوظة بالتاريخ في `LocalStorage`.
- مصدر الألغاز مزدوج: **قاعدة Lichess الحية** (ملايين الألغاز الحقيقية بتقييمات وثيمات من 1400 إلى 2600+ Elo) أونلاين، و**مولّد داخلي مؤكّد شطرنجياً** (مات إجباري في 2/3/4 نقلات) كاحتياطي بدون إنترنت — مع **ترتيب عشوائي تام** للأفكار والقطع.
- زر **«اشرح لي الحل بالعربي»** يحرّك القطع تلقائياً بالأسهم ويعطي تفكيكاً تكتيكياً عميقاً مبنياً على ثيمات اللغز (تضحية، إزالة مدافع، شوكة، تربيط، نقلة بينية...).

### 4) كتاب الـ 50 افتتاحية المدمّرة بالأسهم SVG
- موسوعة تفاعلية من أشهر الافتتاحيات الهجومية (Evans Gambit, Fried Liver Attack, King's Gambit, Najdorf...) بأزرار **[التالي ▶️] / [◀️ السابق]**.
- لكل نقلة **سهم SVG ملوّن** يوضّح مسار القطعة (أخضر للأبيض، أزرق للأسود) مع **شرح عربي مبسّط** يفكّك فخّ سحق الخصم.

### 5) المسابقات الحية أونلاين عبر Supabase Realtime
- ربط طالبين لحظياً عبر **Supabase Realtime Channels** (Presence + Broadcast) — نقل الحركات ومزامنة ساعة الشطرنج بين الجهازين بلا تأخير.
- **روابط تحدٍّ للواتساب** عبر غرف خاصة بكود، ولوحة **صدارة حيّة** تتحدّث أمام الجميع.

## ✨ ميزات المنصّة (Feature Highlights)

> منظومة ضخمة من الميزات الاحترافية تُغطّي اللعب، التعلّم، التحليل، التنافس، الأمان، والمؤثرات السينمائية.

### 🎮 اللعب
- 9 روبوتات بمستويات (مبتدئ 400/800/1000 مفتوحة، ومحترفة 1800/2400/2800 مقفلة بالـ XP).
- ساعة شطرنج فخمة للطرفين، عدّاد الأخطاء الفادحة، تلميح المدرّب، التراجع، الاستسلام، قلب الرقعة، نسخ FEN/PGN، سجل النقلات، وصينية القطع المأسورة وفارق المادة.
- بطولة الصاعد المحلّية ضد سلسلة روبوتات متدرّجة.

### 🧩 التعلّم
- ألغاز تتابعية صعبة (1400 → 2600 Elo) بترتيب عشوائي 100%.
- كتاب 50 افتتاحية تفاعلي بالأسهم والشرح العربي.
- قسم دروس مصوّرة بمشغّل محمي بدون كوكيز.

### 📊 التحليل
- تحليل احترافي بمحرّك Stockfish لكل نقلة + عمود تقييم تفاعلي + تصنيف وألوان النقلات + ملخّص دقّة الأداء.

### 🏆 التنافس
- مسابقات حية أونلاين بين الطلاب، روابط تحدٍّ واتساب، لوحة صدارة حيّة، نظام XP وأوسمة شرفية ومستويات تنافسية (برونزي → ماسي).

### 🔒 الأمان
- جدار حماية للحسابات، رمز هويّة مشفّر، حماية النقاط ضد التعديل من الـ Console، كشف الغش بمغادرة التبويب أثناء المباراة، وتغليف كامل الكود داخل نطاق خاص.

### 🎬 المؤثّرات السينمائية الفاخرة
- **تأثير الأكل السائل السينمائي (Liquid Dissolve):** تذوب القطعة المأكولة بتأثير سائل ناعم متلاشٍ.
- **انفجار الجزيئات (Particle Splash Blast):** رذاذ جزيئات مضيئة بلون القطعة ينتشر حول المربّع.
- **وميض خطر الملك (King Danger Pulse):** نبض أحمر حول الملك عند الكش.
- **كش‑مات سينمائي:** اهتزاز شاشة كامل (Screen Shake) + ذوبان قطع الخاسر + ألعاب نارية واحتفال Confetti + شاشة فوز/خسارة بحروف ذهبية متحرّكة.
- صوتيات WebAudio فورية بلا ملفات، اهتزاز Haptic للجوال، وأنيميشن قطع ناعم خارق (will-change + GPU).

### 🎨 التصميم والتجربة
- ثيم مطفأ كلاسيكي مريح للعين بألوان Chess.com الرسمية (`#eeeed2` / `#769656`).
- ثيمات رقعة متعددة، وضع التركيز، وضع توفير الطاقة، ملء الشاشة الذكي (board.resize تلقائي).
- **تجاوب 100% مع الموبايل** (الرقعة فوق ولوحة التحكّم تحت تلقائياً).

## 🛠️ التقنيات (Tech Stack)

| الطبقة | التقنية |
|---|---|
| الواجهة والمنطق | **Vanilla JavaScript** (بدون أي إطار عمل) |
| قواعد الشطرنج | `chess.js` |
| عرض الرقعة | `chessboard.js` + قطع Wikipedia |
| محرّك التحليل | `Stockfish.js` (Web Worker) |
| الألغاز الحيّة | Lichess Open Puzzle API |
| المسابقات الحية | Supabase Realtime |
| التخزين | LocalStorage (مغلّف ومحمي) |
