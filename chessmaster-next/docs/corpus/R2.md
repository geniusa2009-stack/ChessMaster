## Commands

Run from `scripts/corpus` with the dependencies in `requirements.txt` available:

```sh
python audit_r2.py --verify-raw
python normalize_r2.py --sources chesscom-puzzles --limit 1000 --seconds 30
python normalize_r2.py --sources arcade chessdb-brilliancies --limit 1000
python graph_r2.py --game-limit 1000
python verify_r2.py --stage legal --limit 1000
python verify_r2.py --stage engine --limit 50 --engine /path/to/stockfish --nodes 50000
python query_r2.py --domain puzzles --limit 5
python benchmark_r2.py
python report_r2.py
```

`resume_r2.py` selects incomplete, known-size files within its byte budget and
free-space reserve. Existing partial downloads are deliberately excluded until
validators/range responses are inspected; none existed in the baseline audit.
It does not claim to finish unknown-size or source-failed regional jobs.

Private complete evidence is in `reports/r2-baseline.json`,
`reports/r2-final.json`, and the R2 SQLite tables. `query_r2.py` returns the active
adapter's records and provenance, including mappings retained from older adapters.

## Limits and remaining work

The initial known remaining compressed acquisition requirement alone was
53,668,301,857 bytes. The free disk was below 2 GB. There is no measured full-scale
working-space projection: decompression, complete normalized records, indexes,
solver results and unknown source sizes are additional. The final report records
an exact lower bound, not a promise that a volume of that size is sufficient.

R2 is an additive partial sidecar, **not** a completed global canonical corpus.
Do not add R1 and R2 record counts. Historical adapter outputs and rejected rows
are retained; use the active `normalization_outputs` mappings for current counts.
Global cross-source educational equivalence, equivalent solution groups,
complete game normalization and the complete opening graph remain unfinished.

The R2 engine benchmark added 50 analyses at 50,000 nodes each with Stockfish 19,
one thread, 32 MiB hash and up to three PVs. These are finite evidence, **zero
objective or unique-solution proofs**. Missing composition solutions stay missing.
Popeye proof integration remains pending. Syzygy only probes installed material
coverage and records missing dependencies; it does not imply seven-man coverage.
